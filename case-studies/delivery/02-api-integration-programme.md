# D02 | API Development and Integration Programme

> Replaced bespoke one-off requests with a single Agile operating model, delivering 100+ API and integration initiatives for 16 financial institutions.

| | |
|---|---|
| **Organisation** | Listed West African IT services group |
| **My role** | Senior Product Manager, owning the programme operating model |
| **Period** | Within 2015 to 2023 |
| **Scale** | 100+ initiatives across 16 financial institutions |
| **Relevant for** | Project Manager, Delivery Manager, Technical Project Manager, Business Analyst |

## Context

Financial institutions kept asking for API work and platform customisation. Each request risked becoming a bespoke project with its own surprises, and customisation debt was building up.

## Challenge

Deliver a steady stream of change for regulated customers predictably, without the platform drifting into dozens of one-off versions.

## What I did

Set up one operating model for every request:

1. **Standard intake** so each request arrived with the same minimum information
2. **Requirements workshops** with the customer and technical leads
3. **Estimation and backlog** entry, prioritised against committed work
4. **Sprint delivery** with a traceability matrix linking requirements to tests
5. **UAT with entry and exit criteria** agreed in advance
6. **Release calendar and change approval** so releases did not collide
7. **Deployment checklist** for every go-live
8. **Early life support**, then a post-implementation review

Each new request was checked for reuse, and repeated requests were reviewed for productisation into the standard platform.

## Results

- **100+** initiatives delivered across **16** financial institutions
- One repeatable delivery model in place of bespoke projects
- Customer requirements turned into prioritised, testable work

## Skills demonstrated

Agile delivery at programme scale; requirements management; release and change control; governance that speeds delivery; reuse and productisation thinking.

Scrum, traceability matrix, UAT criteria, release calendar, [sprint templates](../../templates/sprint-planning-and-retrospective.md), [post-implementation review](../../templates/post-implementation-review.md).

# Product Manager vs Senior Product Manager

How the same Agile activities change as responsibility grows.

| Activity | Product Manager (tactical) | Senior Product Manager (strategic) |
|---|---|---|
| Backlog | Prioritise features for the next sprints | Align the backlog to vision and market position |
| Sprint planning | Define sprint scope | Align sprints to the roadmap and wider portfolio |
| Delivery | Remove blockers for the team | Drive improvement across teams |
| Demos and feedback | Run demos and collect feedback | Interpret feedback strategically and change direction when needed |
| Architecture and release | Follow agreed standards | Set architecture principles and release criteria |
| Resourcing | Work within allocated capacity | Allocate resources and set positioning across products |
| Lifecycle | Launch and improve features | Plan entry, growth and retirement of whole products |

In practice, a senior product manager still does the tactical work. The difference is that every tactical decision is checked against strategy, portfolio and commercial outcomes.
